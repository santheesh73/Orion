### Capabilities

</div>

| | |
| :--- | :--- |
| **Local inference**<br>Models run directly in the browser via WebGPU acceleration. | **Offline-first**<br>Continue using Orion without a cloud backend or active connection. |
| **Local memory**<br>Chats, documents, and settings persist securely in IndexedDB. | **Document intelligence**<br>Upload, parse, chunk, search, and chat with local files. |
| **Worker isolation**<br>Generation and parsing run off the main thread for smooth UI. | **Zero telemetry**<br>No cloud inference, no analytics, and zero external tracking. |
